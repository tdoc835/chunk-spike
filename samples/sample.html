Introduction

The HTML parser uses cheerio to extract content from HTML documents. It preserves semantic structure and removes unwanted elements like scripts and styles.

Features

  • Heading extraction (h1-h6)
  • Table parsing
  • Code block detection
  • List handling

Technical Details

Code Example


const $ = cheerio.load(html);
$('h1, h2, h3, h4, h5, h6').each((i, el) => {
    console.log($(el).text());
});

CHAPTER 1

Introduction

This is a sample text document for testing the document chunker. It contains multiple sections with different heading styles.

The document chunker should be able to identify headings and create appropriate chunks from the content.

1.1 Background

This section provides background information about the project. The goal is to create a production-ready document chunker that can handle multiple file formats.

Key Features:
- Multi-format support
- Structure-aware chunking
- Heading hierarchy preservation
- Table and code detection

1.2 Technical Details

The chunker uses heuristics to detect headings in plain text files:
- ALL CAPS lines
- Lines ending with ":"
- Underlined text
